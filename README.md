# trailer-bridge-html

PineIPTV's trailer relay page. YouTube only plays embedded videos for pages
with a web address, and an app installed on a Samsung TV has none, so the
TV app loads `trailer.html` from here; the page embeds the trailer and passes
the player's events back to the app.

It is a copy of `docs/trailer.html` from PineIPTV. When that file changes,
copy it here too.
